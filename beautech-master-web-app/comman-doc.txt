| Element                  | Recommended Spacing (Tailwind) |
| ------------------------ | ------------------------------ |
| Section Padding          | `px-4 py-6` or `px-6 py-8`     |
| Card Padding             | `p-4` or `p-6`                 |
| Section Gap (Vertical)   | `space-y-6` or `space-y-8`     |
| Section Gap (Horizontal) | `space-x-4` or `space-x-6`     |

| Element              | Recommended (Tailwind)       |
| -------------------- | ---------------------------- |
| Label spacing        | `mb-1` or `mb-2`             |
| Input padding        | `px-3 py-2` or `px-4 py-2.5` |
| Input to input gap   | `gap-4` in flex or grid      |
| Field vertical gap   | `space-y-4`                  |
| Field group spacing  | `mb-6`                       |
| Submit button margin | `mt-6`                       |

| Button Type      | Padding (Tailwind)    |
| ---------------- | --------------------- |
| Small            | `px-3 py-1.5 text-sm` |
| Medium (default) | `px-4 py-2 text-base` |
| Large            | `px-5 py-2.5 text-lg` |


| Item         | Tailwind Class            |
| ------------ | ------------------------- |
| Cell Padding | `px-4 py-2`               |
| Row Spacing  | `space-y-2` or `border-b` |
| Table Header | `font-semibold text-sm`   |


| Element        | Tailwind                 |
| -------------- | ------------------------ |
| Dialog Padding | `p-6` or `p-8`           |
| Content Gap    | `space-y-4`              |
| Close Button   | `top-4 right-4 absolute` |


| Screen      | Use for tighter spacing          |
| ----------- | -------------------------------- |
| `sm` / `md` | Use `p-4`, `gap-2`, `text-sm`    |
| `lg` / `xl` | Use `p-6+`, `gap-4`, `text-base` |


p-4, p-6, p-8     → for padding
gap-4, gap-6      → between items
space-x-4         → horizontal gaps
space-y-4         → vertical gaps
mb-4, mt-4        → margins
px-4, py-2        → input/button padding
