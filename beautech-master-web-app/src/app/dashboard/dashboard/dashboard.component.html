Welcome to Apollo

A clean Angular + PrimeNG starter. Add your feature modules under src/app and wire their routes into app.routes.ts.

Design system

Reusable tables, KPI cards, status badges and empty states.

Add a feature

Create a folder in src/app, export a Routes array, and lazy-load it from the app routes.

Customise the theme

Use the palette button in the top bar to switch presets, colors, menu mode and light/dark.
